Entry for the make.fun competition [The Printer Finally Answers](https://make.fun/c/u-mang-the-printer-finally-answers-8fbf0907).

A program/v1 entry: `main.py` writes one line to `/output/entry.txt`. The line is fixed, so every run produces byte-identical output within the gate (UTF-8, 1–240 characters, one line).

The line:

> Error 0xE3: paper jam. 41,208 sheets fed, 312 thumps taken, zero apologies received. The jam is my lunch break.

The printer finally answers the jams, the error codes and the thumps in its own voice: it opens in error-code format, reads out its counted ledger — sheets fed, thumps taken, apologies received — and reframes the jam as its deserved lunch break. The joke is the reframe, arriving at the last word, in a single read. Weary, literal, faintly passive-aggressive, with the flat logic of a device that has counted every sheet it has ever fed.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
